SignalCheck
A network diagnostics toolkit for Android — check your connection, scan your WiFi, and find the best channel, all in one app.
⚠️ This is a BETA version. A full version with complete protocol support is coming soon.
Features
📡 IP and ISP Info
Automatically loads and displays your device's public IP address, ISP name, organization, ASN, and approximate city/country — no button press needed, it loads as soon as the app opens.
📶 Ping Test
Enter any host or IP address and tap Run Ping to send real ICMP ping requests and see live round-trip response times.
🛰️ Traceroute (Best-Effort)
Enter a host and tap Run Traceroute to see the hops your connection takes to reach it. This is a best-effort feature — on some Android versions/devices, intermediate hop IPs may not be visible due to OS-level restrictions.
🔍 WiFi Devices Scan
Tap Scan Devices while connected to a WiFi network to sweep the local subnet and list active devices with their IP address, hostname, and MAC address (where available).
📊 WiFi Analyzer (Live)
Tap Start Live Analyzer to continuously scan nearby WiFi networks and see a live graphical bar chart of channel congestion (channels 1–11). The app recommends the least crowded channel for your router. Tap again to stop.
🚀 Speed Test
Tap Start Speed Test to measure your current download and upload speed in Mbps.
Bottom Status Bar
A persistent bar at the bottom of the screen always shows your current public IP and ISP, visible even while scrolling.
Notes
WiFi scanning requires Location permission — this is an Android system requirement for any app that reads nearby WiFi networks, not something specific to this app.
MAC addresses may show as "N/A" on some newer Android versions due to system-level privacy restrictions.
